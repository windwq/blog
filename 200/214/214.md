# 《GTA6》攻略笔记

## 前言

2018-10-26《荒野大镖客 2》发布时，我没有 PS4，只能看着整个游戏圈狂欢。一年后 2019-11-05，我才在笔记本电脑上，**以 960M 显卡、泛白 TN 屏、不稳定的 20 帧，玩了 170 小时**。我喜欢新鲜感，所以很少二周目，《荒野大镖客 2》在我电脑里躺了几个月，我也没再用 5090 显卡重玩一遍。  
这一次《GTA6》，我终于不再等待。我有 PS5 Pro、4K 显示器、DualSense Edge 手柄，还有音箱能听手柄喇叭。  

现在**用 AI 查游戏攻略**挺好用的，我也在用。有 AI，就几乎没有图文攻略的生存空间了。  
但是：  

- 现在的 AI 还在埋头刷题（ [AI对黎曼猜想的证明，正式通过形式化验证！](https://www.bilibili.com/video/BV1DjybzFEed) ），不喜欢玩游戏，在攻略方面还是偷人的理解。
- 靠谱的人写的内容让人信任，不靠谱的人写攻略半真半假。
- 记录本身就有意义。我还有好几个游戏，像《荒野大镖客 2》那样，写了几千上万字的攻略，但从未发布过。

**这次的「攻略笔记」每天更新**，不再像之前通关游戏之后才发布。会有未完成的部分。

## 评价

### 优点

- 文本翻译，地道。
- 对 DualSense 手柄的适配不错。第一章就展显了打螺丝、钉钉子两种不同的自适应扳机体验。震动也多样。可能是适配最好的第三方游戏。
- 小游戏：台球、游戏机
- 丰富的手机内容（且带翻译），可以在坐出租、床上玩手机

### 缺点

- **运动物体有拖影**：篮球、台球、等等。
- **景深、暗角效果无法调节**，画面看着好像眼睛睁不开。[数毛社](https://www.bilibili.com/video/BV1gFsS69E5F?t=488.5) 也指出了这点。
- 输入延迟，画面不跟手。祖传的毛病。

### 吐槽

- 不能通「曼迪」的「管道」。可能是因为 Jason 看到 Jensen Huang 的下场，害怕了。
- 家附近的车不能偷，不能掏武器。

## 入门

### 设置

**过一遍游戏设置，改成自己最舒服的体验**。比如：  
字幕、开车时的镜头跟随、移动速度、连按辅助、计量单位  


### 地图

一个屏幕放着第三方地图，有空就看一眼。拿收集品、做支线。  

**游民星空**  
<https://www.gamersky.com/tools/map/gta6/>  
近几年他们做的地图都不错，不需要登录账号就能用大部分功能。而且是玩家合作的，速度快，评论区能纠错。  
我也在参与新增、编辑点位。  

**MapGenie**  
<https://mapgenie.io/grand-theft-auto-6/maps/leonida>  

室内适合用 3D 视角，室外还是 2D 好用。  

### 操作

帮助里有，但有必要单独强调。  
按使用频率排序。  

| **操作**           | **按键**        |
| ------------------ | --------------- |
| 放大、第一人称观察 | 按 L2，再按 R3  |
| 跳车、下车不熄火    | 连按 2 次三角键 |
| 开车时与 NPC 互动     | 按住十字上键           |
| 推车、让车翻面     | 先推摇杆顶住车，再长按方块键        |
| 车中躲避          | 长按圆圈键        |
| 用车门撞人、摩托车踢人    | 按方块键        |
| 快速切换武器    | 瞄准时按三角键        |
| 对比武器属性           | 装备武器时，长按 L1    |
|                    |                 |
| 驾驶时嘲讽       | 按 R1 竖中指、按 R3 骂人 |

### 小技巧、冷知识

**时间**  
在地图、菜单界面，不会计入「统计数据」的「游玩时长」。  
（部分）任务中，时间是暂停的。  

自己家附近：不能掏武器、不能偷车。  

**专注状态**  
非战斗状态不消耗「专注值」。走到哪就开一下，镜头转一圈。  

**第一章结尾，银行账户（元交）会被清空**  

**藏货袋**  
随身带着，没放在车上的话，死或被捕后，货会消失吗？  

**武器**  
独特武器改款：拾取一次后就为两个角色永久解锁，不需要存到后备箱。  

TODO:错过健身时段，会发生什么？  

**收藏卡**  
黄盒子的内容物是随机的：卡（随机）、现金、烟、墨镜、没东西  

上飞机后自动装备降落伞。

**篮球**  
一个球 1 分，好像没有其他分数。连续进球，屏幕右侧提示的分数是累计的。
